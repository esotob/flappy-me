### 🧠 Learned
- Git stores text efficiently, but binaries (images, audio) bloat the repo → Git LFS stores them separately.
- `git lfs install` only enables LFS; `.gitattributes` defines which files it tracks.
- `Library/`, `Temp/` and `Logs/` are regenerated by Unity and must never be committed.
- `.meta` files hold asset IDs; without them references break.
- **Force Text** serialization lets Git diff scenes and prefabs.
- Unity always creates a subfolder with the project name, so the project had to be moved to the repo root.
- Docs go outside `Assets/` so Unity doesn't import them.
